# Official references

Use these primary sources to verify current product behavior. The guide is independent; it does not confer approval or certification.

## Models and prompting

- [OpenAI API model catalog](https://developers.openai.com/api/docs/models) — current model identifiers and published capabilities.
- [Prompt engineering guide](https://developers.openai.com/api/docs/guides/prompt-engineering) — current API prompting guidance and links to model-specific material.

## Evaluation

- [Evaluation best practices](https://developers.openai.com/api/docs/guides/evaluation-best-practices) — designing evaluations for model applications.
- [Evals and evaluation learning resources](https://developers.openai.com/learn/evals) — guides and examples. Check lifecycle notices on linked evaluation tools before adopting them.

## Data and privacy

- [OpenAI enterprise privacy](https://openai.com/enterprise-privacy/) — published business-data commitments.
- [ChatGPT data controls](https://help.openai.com/en/articles/7730893-data-controls-in-chatgpt) — account-level controls and plan-dependent options.

## How to use these links

- Recheck model IDs, features, pricing, limits, and deprecation notices immediately before implementation or publication.
- Distinguish ChatGPT product behavior from API behavior; settings may differ by surface, plan, and workspace.
- For enterprise use, have the workspace owner or responsible security and privacy teams confirm applicable policies and controls.
- Record the source and the date checked when a product-specific claim matters to a decision.
